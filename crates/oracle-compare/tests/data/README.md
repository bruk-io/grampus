# Comparator test fragments

These G-code fragments are hand-written, not captured from a real oracle run: this task (part 1
of plan step 5) must build and pass its tests on a machine with no oracle binary and no libslic3r
build, so it never invokes the oracle and commits no file a run of it produced.

The plan's "pair taken from two real runs of Step 2" is committed by task
**`10-comparator-json`**, the last part of step 5, which depends on `04-oracle-slice` and so has
the oracle available.

| Directory | What it covers |
|---|---|
| `identical/` | Byte-identical pair: L0 and L1 both pass. |
| `generated_by/` | Differ only in the `; generated by ` timestamp line: L0 fails, L1 passes. |
| `plugin_armed/` | One side carries a `slicing_pipeline_plugin` config line the other lacks (the armed-against-unarmed shape Step 8's dumper produces): L0 fails, L1 passes. |
| `model_label/` | Differ in a `; model label id: ` line and in both the start and stop `..., unique label id: N` lines: L0 fails, L1 passes. |
| `one_coordinate/` | Differ in one `G1` coordinate, which no normalisation rule touches: both L0 and L1 fail. |
| `unrelated/` | Two unrelated files: both L0 and L1 fail from the first byte. |
